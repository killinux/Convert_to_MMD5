# 脸骨表情设计(convert/face.py)

给**脸靠骨骼驱动、没有形态键**的模型做 MMD 标准表情(PMX 骨骼 morph)。当前支持 UE MetaHuman 式脸骨,
以 Fiona(Vindictus,blender2xps 导出的 XPS)为样本开发与验证。

> 2026-10-01 起,这里是表情引擎(`expression/`)的「脸骨」来源(`sources.FaceBoneSource`):本文的算法不变,
> 写 morph、按钮、标记改由引擎负责,也能烘焙成顶点 morph,见 [expression_design.md](expression_design.md)。
> 下文「按钮」指现在第 3 页的「生成表情」(来源 = 脸骨或自动,方式 = 骨骼或自动)。

## 1. 样本脸骨实测(Fiona)

- 网格里**没有任何形态键**(XPS 格式本身不带),脸完全靠骨骼:`FACIAL_C_FacialRoot` 下 617 根 `FACIAL_*`,
  489 根带权重;另有 `首` 下 `FACIAL_C_Neck1Root`/`Neck2Root` 两组颈部皮肤骨。
- 结构(决定了能怎么动):
  - 眼皮:`FACIAL_[LR]_Eyelid{Upper,Lower}{A,B}` 的**父骨头部就在眼球中心**,子骨 A1~A3/B1~B3 在眼睑边缘,
    上睫毛骨 `EyelashesUpperA*` 是 A* 的子骨;下睫毛直接刷在 `EyelidLowerA*` 上。
  - 下巴:MetaHuman 的 `FACIAL_C_Jaw` 被 blender2xps 改名成 XPS 标准名 `head jaw`(下挂 Chin/Jawline);
    **下唇、下牙、舌头挂在另一根 `FACIAL_C_LowerLipRotation` 下**,轴心与下巴骨重合。
  - 嘴:`FACIAL_C_MouthUpper` 下是上唇与两侧嘴角 `LipCorner`,`FACIAL_C_MouthLower` 下是下唇;
    唇骨本身不带权重,权重在它们的 12IPV 子骨与 *Skin 骨上。
  - 眉:眉毛是单独网格(毛片),刷在 `Forehead{In,Mid,Out}*` 上,约 15% 在 `EyesackUpper` 上。
  - 舌头在牙齿网格里,只有约 40 个顶点;`FACIAL_C_Tongue1` 在 Blender 里是**连接骨**。
- 权重(XPS 每顶点 4 骨):眼睑皮肤顶点有一部分刷在头骨/眼角骨上。上眼睑边缘实测:中段不跟转份额
  0.06,内外眼角附近 0.53。

## 2. 方法:场 → 逐骨目标变换 → 局部偏移

每个表情 = 若干「场」按顺序叠加;场按骨头的静止位置给出这根骨在骨架空间的目标变换 D(旋转绕某轴心 + 平移)。
最后换成相对父骨的局部偏移写进 mmd_tools 骨骼 morph:

    pose = rest⁻¹ · D_parent⁻¹ · D · rest

父骨动了而自己该留在原处的骨,会自动得到抵消项。坐标系:lat = 右眼→左眼,fwd = 脸朝向,up;
**平移单位 = 两眼间距**(Fiona 5.59 cm)。

| 场 | 作用对象 | 做法 |
|---|---|---|
| lids | 眼皮 | 绕眼球中心的横轴转。闭合角逐骨 = 该横向位置上下眼睑边缘的仰角差 × (走的份额) / (1−h),见 §3 |
| jaw | 下巴 | 绕下巴骨头部转,再沿 fwd 前滑到「下颌支中点」前后不动(髁突前滑,否则下颌角被挤进脖子)。下巴/下唇子树全跟;嘴角、脸颊、法令纹、咬肌、颌下、上颈皮肤骨按 w = d_不动 /(d_不动 + d_下巴) 跟随(d 为到两组锚骨的最近距离;不动锚含下颈骨) |
| corners | 嘴角 | 平移。嘴角子树全动;唇骨按横向位置 smoothstep(x/x_嘴角)(中线不动);唇外按到嘴角距离高斯衰减(σ = 0.3) |
| lip | 唇中 | 平移,权重 1 − smoothstep(|x|/半嘴宽);`flat` 时整片唇 |
| brows | 眉 | 沿眉的横向位置在 内/中/外 三段量之间插值;额头皮肤、眉间、鼻梁、上眼皮褶按到最近眉骨的距离高斯跟随(σ = 0.35,中线骨每侧各半) |
| cheeks | 颧部 | 按到颧部中心的距离高斯上提(σ = 0.45) |
| tongue | 舌 | 排在 jaw 之后:以舌根**张嘴后**的位置为轴心转,再沿 fwd 伸出 |
| teeth | 牙 | 歯無し:把牙缩回头里 |

轴心本身就在骨头上的(眼皮父骨、下巴骨)只带旋转:MMD 按权重插值时走圆弧,半闭时眼皮不陷进眼球。

## 3. 眼皮闭合的标定

1. 皮肤网格 = 以唇骨为主导骨的顶点最多的网格(睫毛/眉/牙网格没有唇)。
2. 对每根边缘骨(`EyelidUpperA` / `EyelidLowerA` 的子骨),取它为主导骨的皮肤顶点:上眼皮取仰角最低的 1/4、
   下眼皮取最高的 1/4 当「边缘」,记横向位置、仰角、不跟转份额 h(权重落在该眼皮旋转骨集之外的比例)。
3. gap(x) = 上缘仰角 − 下缘仰角(按横向插值)。`close`=1、`meet`=m 时,上眼皮走 (1−m)·gap、下眼皮走 m·gap,
   各除以 (1−h(x))(上限 ×1.6)。`tilt` 让上眼皮外端(>0)或内端(<0)多合。
4. 上眼皮褶/眼窝(`EyelidUpperFurrow`、`EyesackUpper`)按高度在「眼皮最高骨 → 眉骨平均高度」间线性递减跟随;
   下眼袋同理到颧部。

Fiona 实测眼裂中段 34°。

## 4. 表情表

59 个,名字/分类照 MMD 标准 + Tda 式常见补充(动作里常见的别名、单侧眉/眼)。主要参数(平移单位 = 两眼间距):

- 目:まばたき(close 1, meet 0.25)、笑い/ウィンク(meet 0.55 + 颧部上提 0.05)、ウィンク２(同眨眼)、
  なごみ(0.8/0.35)、はぅ(1.08/0.5 + 颧 0.03)、びっくり(−0.3)、じと目(0.35 只动上)、キリッ(0.18/0.5, tilt −0.08)、
  下眼上、怒り目/悲しむ(tilt ∓0.12)。
- 口:あ 15°、あ２ 22°、い(嘴角外 0.07 + 4°)、う(嘴角内 0.08 前 0.04、唇前 0.045、1.5°)、え(0.04 + 9°)、
  お(内 0.05、唇前 0.02、12°)、にっこり/にやり/にやり２(嘴角上 0.07~0.10)、ぺろっ(14° 后舌伸 0.7、下压 15°)、
  てへぺろ(+舌偏 20° + 单眼笑)、口角上げ/下げ、口横広げ/狭め、▲、∧、ω、ω□、ん、ワ、歯無し上/下。
- 眉:真面目/困る/にこり/怒り/上/下(上 = 0.11),及 困る/にこり/怒り/上/下 的 左/右。

## 5. 调参记录(都有渲染/数值依据)

| 问题 | 原因 | 处理 |
|---|---|---|
| 左眼眨眼闭成 V 形 | 整片眼皮用一个平均补偿系数(不跟转份额约 0.31 → ×1.45),中段(实际只有 0.06)过冲 | 改为逐根边缘骨按网格实测边缘 + 各自的 h 标定 |
| 悲しむ 上眼皮撕开 | tilt 0.3 让内外转角差到 57° | tilt 0.12 |
| 张嘴下颌角凹进、轮廓折角 | 只绕下巴骨转,下颌角往后挤进脖子 | 加髁突前滑:下颌支中点前后不动 |
| 侧面看颌下一道褶 | 颌下骨几乎 100% 跟下巴、脖子不动 | 上颈皮肤骨也按距离插值跟随,下颈骨当不动锚;插值由平方反比改线性,过渡更缓 |
| ぺろっ 舌头出不来(1) | 舌头先前伸再随下巴转,被转进下唇/下巴里 | 舌头排在张嘴之后,轴心取张嘴后的舌根 |
| ぺろっ 舌头出不来(2) | `FACIAL_C_Tongue1` 是连接骨,Blender 忽略它的位移 | 点按钮时断开要平移的连接骨(PMX 没有连接概念,导出不变) |
| 断开连接后名字读出乱码 | 进出编辑模式后 Bone 引用失效 | Face 里预存骨名/位置,之后只按名字用 |

## 6. 验证(Fiona)

- 眼球可见面积(把眼球染色渲染后数像素):まばたき/笑い/ウィンク/はぅ 两眼 0;なごみ 0~3%;じと目 47~54%;
  びっくり 133~137%;半权重眨眼约 35%,眼皮不陷进眼球。
- 按钮:建 59 个(眉 16 / 目 19 / 口 24),7889 条骨骼偏移,用到 459 根脸骨;重复点仍是 59 个;建完姿势清零;
  「表情」显示枠 59 项。
- 导出 → 用 mmd_tools 导回,逐个表情比每根骨的骨架空间变换:纯平移的表情差 ≤ 0.0005 mm,带旋转的差 ≤ 0.04°。
- 反例:Purifier Inase 18(非 MetaHuman 脸)→ 提示「没有可用的脸骨」并取消,「清除表情」不动它自带的 19 个表情。
- 交付:`Fiona_BaseBody.pmx` 1064 骨 / 272 刚体 / 256 关节 / 59 骨骼表情。MMD 里的实测结果待补。

## 7. 已知问题与后续

- 只支持 MetaHuman 式脸骨。别的骨骼脸(如 Rise of Eros 的 32 根脸骨)要另写骨名→角色的对应。
- 只有骨骼 morph:瞳小、照れ、星目等需要材质/UV morph 的没有做。
- 游戏模型舌头很简陋(约 40 顶点),伸出来偏方;あ２(22°)侧面看下颌角后仍有一道褶。
- 幅度只在 Fiona 上按渲染调过;`ウィンク` 取笑眼式、`ウィンク２` 取普通闭眼(与部分模型相反)。
