# Convert to MMD 5 使用说明

把 XNALara / XPS 骨架的模型转成 MMD 模型(PMX)的 Blender 插件。这份说明讲**怎么用**:
装好、点哪些按钮、怎么导出、在 MMD 里看什么。逐步细节、原理和排错见 [操作手册](操作手册.md)。

---

## 1. 它能做什么

- **骨架转换**:XPS 骨架 → MMD 标准骨架——日文骨名、センター/グルーブ/腰、足IK/つま先IK、
  腿 D 骨、腕捩/手捩、肩P、付与,一键完成;网格权重同步整理(转移 helper 骨权重、捩骨/掌骨分权重)。
- **物理(可选)**:身体碰撞刚体、布(裙/外套/披风/披肩/飘带)、胸部、头发。
  刚体/关节参数取自同系列参考 PMX 的实测值,按模型身高自动缩放。
- **表情(可选)**:两种输出,**都是可选项**:
  - **MMD 表情**:まばたき、笑い、ウィンク、眉、あいうえお、ぺろっ 等标准表情(骨骼或顶点 morph),
    动作里的表情关键帧就能驱动;
  - **Faceit(ARKit 52)**:52 个 ARKit 形态键并注册到 Faceit,给 Blender 里的 iPhone 面捕实时驱动。
  表情来源:MetaHuman 脸骨、FF7 Remake / Rebirth 脸骨、MetaHuman DNA、模型自带的 ARKit 形态键、姿势库、骨骼脸,
  默认自动选;任何一个表情都能载入到骨架上**手调**,生成时优先用手调版。
- **不做的**:不负责导入 XPS(用 XNALaraMesh);既没有脸骨、也没有 ARKit 形态键的脸做不了表情;
  头发物理只用模型**已有**的发骨,没有发骨的模型不会自动造发骨(胸部没有骨会自动造)。

## 2. 安装

1. 准备 **Blender 3.6**(3.6.15 上验证),并安装启用:
   - [mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)(PMX 导入/导出,必需)
   - XNALaraMesh(导入 `.xps` / `.mesh.ascii`)
2. 把整个 `Convert_to_MMD5` 目录放进 Blender 的插件目录
   (Windows:`%APPDATA%\Blender Foundation\Blender\3.6\scripts\addons\`),
   或打成 zip 在「编辑 → 偏好设置 → 插件 → 安装」里装。
3. 在「偏好设置 → 插件」里启用 **Convert to MMD 5**。
   原版 Convert to MMD / MMD4 等同类插件要**禁用**,它们的按钮 ID 相同,会互相覆盖。
4. 3D 视图按 **N** → 右侧 **Convert to MMD** 标签页就是面板。

> 面板最上面一行是 **build 时间戳**,代表当前加载的代码版本。更新插件文件后要**重启 Blender**,
> 看到时间戳变了才算生效。不确定 Blender 加载的是哪个目录时:偏好设置 → 插件 → 展开本插件,
> 「文件」一行就是实际路径。

## 3. 最快用法(大多数模型 5 步)

1. `文件 → 导入 → XNALara/XPS Model` 导入模型。**不要缩放骨架**(保持导入时约 1.7 m 高)。
2. 选中骨架 → 面板第一个 tab「**主骨骼管理**」→ 点 **一键转换 XPS→MMD(标准)**。
   状态栏/控制台出现 `一键转换完成: 16/16 步成功` 即可。
3. (可选)切到第二个 tab「**衣服 / 刚体**」,按需依次点:
   **1. 身体碰撞刚体(自动)** → **2. 布物理** → **胸部物理(自动)** → **头发物理(自动识别发骨)**。
   要表情的,再到第三个 tab「**表情**」勾 **MMD 表情** 和/或 **Faceit(ARKit 52)**,点 **生成表情**
   (来源保持「自动」即可;MetaHuman 脸有 `.dna` 的话填上,效果更好、也才能做 ARKit)。
4. 选中模型里任意一个对象(骨架即可)→ `文件 → 导出 → MikuMikuDance Model (.pmx)`:
   **Scale 填 12.5**、勾 **Copy textures**,存到一个**单独的空文件夹**。
5. 在 MMD 里加载 PMX,配一段舞蹈动作实测(物理演算设为「**常に演算**」)。

识别不对、要手动改槽位的模型,看下面第 4 节的「手动分步」。

## 4. 面板说明

### 第一个 tab「主骨骼管理」——骨架转换

| 位置 / 按钮 | 作用 |
|---|---|
| **标准·重建权重 / 精简·保源权重** | 转换路线开关,一键和手动分步都跟随它。**标准**:转移 helper 骨权重、重建捩骨/掌骨,适合大多数模型;**精简**:源权重一律不动(分步 3/6/11/12 变灰停用),适合 helper 骨本身就承重、源蒙皮已经很好的模型 |
| **一键转换 XPS→MMD** | 自动识别骨架 + 全部转换步骤一次做完(**每次都会重新识别并覆盖槽位**) |
| **自动识别骨架(填充下方槽位)** | 只识别、填槽位,不转换。先按骨架拓扑认骨,骨名是 XPS 标准名时按名字优先 |
| 预设下拉框 / **导入预设** / **导出预设** / **✕** | 下拉框选中即把该预设填进槽位;导入/导出是读写外部 json;✕ 清空全部槽位 |
| **槽位**(センター、上半身、首、頭、腕、足、手指 …) | 每个 MMD 骨对应源骨架里的哪根骨。带 `*` 的是主干骨,认错一根后面全错,务必核对。左边放大镜按钮 = 在姿态/编辑模式下用当前选中的骨填这一格(手指选第一节会自动补全整条) |
| **手动分步 0.5、1~15** | 与一键等价,从上到下依次点;适合改过槽位、或要检查中间结果的情况。0.5「转换为 A-Pose」只在源模型是 T-Pose(手臂水平)时点 |
| **拉直手臂(肘+腕)** | 可选工具,不在流程内 |

**手动分步**的顺序(按编号点,9 之前是转换前、之后是转换后):

```
0.5 A-Pose(可选) → 1 归正 → 2 重命名 → 3 转移 unused 权重① → 4 修正前腕 → 5 补全缺失骨
→ 6 转移 unused 权重② → 7 MMD IK → 8 骨骼集合 → 9 mmd_tools 转换
→ 10 腿 D 骨 → 11 捩骨 → 12 手部权重修正 → 13 肩P → 14 设置付与 → 15 应用付与
```

> 手动改槽位后**不要再点一键**(它会重新识别、把你的修改覆盖掉),改走手动分步。
> 14、15 是两步,要连着点。

### 第二个 tab「衣服 / 刚体」——衣服权重与物理

| 区域 | 按钮 | 作用 |
|---|---|---|
| 衣服权重 | **衣服权重转移(身体→衣服)** | 贴身衣物蒙皮很差时,把身体权重转给衣服。先选衣服网格(可多选),**最后加选身体** |
| 刚体 / 物理 | **1. 身体碰撞刚体(自动)** | 给头、颈、躯干、肩、手臂、腿建跟骨走的碰撞刚体,粗细按网格实测。布/发物理靠它挡住不穿身 |
| | **2. 布物理: 裙/外套/披风(自动)** | 按骨名识别布骨(skirt/coat/cloak/shawl/veil/scarf/ribbon…),逐骨建刚体 + 关节 |
| 胸部物理 | **胸部物理(自动)** | 下面 1 + 2 一次做完 |
| | **1. 胸骨 + 权重** | 已有带权重的胸骨就直接用;没有就按网格找乳尖,新建 `左胸`/`右胸` 并分出权重(总权重不变) |
| | **2. 胸部刚体 + 关节** | 每侧一个球形刚体 + 关节 |
| | **清除胸部物理** | 删掉本工具建的刚体/关节;本工具新建的胸骨连同权重并回父骨后删除 |
| 头发物理 | **头发物理(自动识别发骨)** | 把 `頭` 下面名字像头发的骨(hair / 髪 / ponytail / braid / bangs …)连成发链,建刚体 + 关节 |
| | **头发物理(只用选中骨)** | 发骨名字不规范时用:姿态模式里选中每条发链的**第一根骨**(后代自动带上)再点 |
| | **清除头发物理** | 删掉本工具建的刚体/关节,骨骼和权重不动 |

### 第三个 tab「表情」——MMD 表情 / Faceit

面板从上到下:

| 区域 | 按钮 / 选项 | 作用 |
|---|---|---|
| 来源 | 下拉框 | **自动**(默认):给了 DNA 用 DNA → 模型自带的 ARKit 形态键 → FF7 脸骨 → MetaHuman 脸骨 → 骨骼脸。也可以手动选(见下表) |
| | **DNA(可选)** | 这张脸的 MetaHuman `.dna`。给了就用游戏原始的表情数据,MMD 和 ARKit 都能做 |
| | **表情数据**(FF7 脸骨时出现) | FF7 角色的表情数据 JSON;放在 `.blend` 上层的 `_meta/face` 里会自动找到,空着就行 |
| | **分析模型** / **兼容性检查** | 分析:模型有什么、「自动」会选哪个来源、脸部权重情况;检查:现在进 MMD / Faceit 会出什么问题 |
| 输出(可多选) | **MMD 表情** + 方式 **自动 / 骨骼 / 顶点** | 进 PMX 的 MMD 标准表情。骨骼:体积小,半程时眼皮/下巴走圆弧;顶点:MMD 里和 Blender 一模一样;**自动**(默认):逐个表情估算 PMX(每顶点只留 4 个权重)里的偏差,不超过 0.3 mm 做骨骼,否则做顶点 |
| | 目 / 眉 / 口 / 其他、**扩展表情**、**替换同名** | 做哪几类;扩展 = 别名和单侧表情(动作里常见);替换同名 = 模型自带的同名表情也重做(默认跳过,不碰) |
| | ▸ 强度 / 阈值 / 配方 / 误差预估 | 各类表情的强度、自动方式的阈值、自定义配方 JSON、只估算不生成 |
| | **Faceit(ARKit 52)** | 52 个 ARKit 形态键;勾「生成后注册到 Faceit」时顺带注册(形态键、头骨、实时源,默认 Face Cap) |
| | **注册到 Faceit** | 单独注册(比如生成后才启用 Faceit)。完成后面板显示手机要填的 IP 和端口。模型不朝 -Y 时顺带把它转过来(见下) |
| 按钮 | **生成表情** | 按勾选一次做完。可以重复点:本工具做的会按当前设置重做 |
| | **清除 MMD 表情** / **清除 ARKit** | 只删本工具做的,模型自带的不动 |
| ▸ 手调 | 表情组(ARKit / MMD)、◀ 表情 ▶ | 选要改的表情,◀ ▶ 换上一个 / 下一个并直接载入 |
| | **载入到骨架** | 把这个表情摆到脸骨上(有手调用手调,没有用来源算的初稿),接着在姿势模式里改 |
| | **保存手调** / 🗑 | 把脸骨现在的姿势存成这个表情的手调版 / 删掉手调回到初稿 |
| | **镜像到另一侧** | 骨架上的姿势左右镜像,存成对侧的表情(eyeBlinkLeft → eyeBlinkRight、ウィンク → ウィンク右) |
| | **复位**、**手调优先** | 脸骨回到静止;生成时有手调的表情用手调版(默认开) |
| ▸ 预览 | 表情 + 权重、**↺ 归零** | 在 Blender 里看任一个生成的表情;**导出前点归零** |
| ▸ 工具 | **恢复完整权重** | DNA 来源时,从 UE5 游戏包(`.uasset.bin`)补回 UE Viewer 截掉的权重,表情不鼓包 |
| | **转换前暂存形态键** / **转换后恢复** | 模型本来就带形态键(如 ARKit)时,一键转换前后各点一次 |
| | **导出 PMX**(带 ARKit 形态键 □) | ×12.5 导出;默认**不把** ARKit 形态键写进 PMX(否则多 52 个「其他」表情、文件大 5 MB 左右) |
| | **导出配方** | 把内置配方写成 JSON,改完在「配方」里载入 |

来源怎么选:

| 来源 | 适合的模型 | MMD 表情 | ARKit 52 |
|---|---|---|---|
| **脸骨(MetaHuman)** | 有 UE MetaHuman 式脸骨 `FACIAL_*`(blender2xps 导出的 UE 模型,如 Fiona),没有 DNA | 59 个 | 做不了(要 DNA) |
| **FF7 脸骨** | FF7 Remake / Rebirth 游戏导出的 `.blend`(脸骨 `C_FaceBase_a`),配表情数据 JSON | 31 个 | 52 个 |
| **MetaHuman DNA** | 同上,并且有这张脸的 `.dna` | 约 56 个(含 瞳小;ω、歯無し 没有配方) | 52 个 |
| **已有形态键** | 模型自带 ARKit 形态键(星刃 mod、VRoid Perfect Sync、CC4 ……) | 约 50 个,只能做顶点表情 | 已经有了,直接注册 |
| **姿势库** | 任何骨骼脸:自己摆好姿势「记录」,名字用 MMD 名或 ARKit 名;或带姿势标记的动作 | 记录了哪些做哪些 | 同左 |
| **骨骼脸** | 只有眼皮 / 眉 / 下巴 / 嘴唇 / 舌头骨的脸(Rise of Eros 式) | 59 个 | 48 个(实验性) |

- 做了哪些 MMD 表情:眉(真面目/困る/にこり/怒り/上/下,及单侧的 左/右)、目(まばたき/笑い/ウィンク/ウィンク２/
  なごみ/はぅ/びっくり/じと目/キリッ/瞳小 等)、口(あいうえお/▲/∧/ω/にっこり/にやり/ぺろっ/てへぺろ/
  口角上げ・下げ/口横広げ・狭め/歯無し 等)。常见的两种写法都带上了(如 `ｷﾘｯ`/`キリッ`、`ジト目`/`じと目`)。
- **Faceit 表情只给 Blender 用**:iPhone 上的 Face Cap / Live Link Face 通过 Faceit 实时驱动这 52 个形态键;
  MMD 的动作不认这些名字。Faceit 是另外安装的付费插件,没装或没启用时形态键照样生成,启用后点「注册到 Faceit」。
- **注册时模型可能被转向**:Faceit 按角色朝 -Y(正视图)换算手机传来的头部转动。FF7 这类 UE 游戏导出的模型
  朝 +X,不转的话点头会变成歪头,所以注册时会把整个模型绕 Z 轴转到朝 -Y(只改物体的旋转,不动网格数据),
  报告里写明转了多少。转换好的 MMD 模型本来就朝 -Y,不会动。
- 换来源重做时,新来源做不了的表情(如 DNA 没有 ω)保留上一次做的。想全部换掉就先点「清除 MMD 表情」。
- **FF7 Rebirth 角色做 Faceit**:打开游戏导出的 `.blend`(带脸骨的原始 blend,不是转好的 PMX)→ 选骨架 →
  第 3 页勾「Faceit(ARKit 52)」→ 生成表情。52 个形态键由游戏的表情姿势、口型和少量按骨骼算的动作组成;
  哪个不满意就在「手调」里载入、改、保存,再生成。表情数据由 ripper_tpose 的 `ff7rb_face_data.py` 生成
  (表情姿势和口型都是 Rebirth 自己的;个别解不出的姿势可以从 Remake 的数据补)。
- 没有配方的表情(比如 MetaHuman 脸骨做 ARKit)也可以在「手调」里自己摆出来保存,生成时就有了。
- 旧版(只有「用脸骨做 MMD 标准表情」一个按钮)做的表情会被新版认领:可以直接重做或清除。

## 5. 加物理的顺序和注意事项

1. **先点「身体碰撞刚体」**,再点布物理和头发物理;胸部物理前后都行。
2. 所有物理按钮都可以**重复点**,已经有刚体的骨会跳过。胸部、头发各有「清除」按钮,只删本工具建的。
3. **导出前不要点 mmd_tools 的 Build**(物理预览)。Build 过的场景一求值,骨骼就被物理带离原位,
   导出的 PMX 一开场关节就被拉开,在 MMD 里会炸。点过的话先点 Clean 再导出。
4. 头发物理的几条规则,知道了好判断结果:
   - 发根、帽盖这类**分叉**的骨跟着头走,只有从分叉往下的单条发链会晃;
   - 名字带 hair 的脸部骨(如 UE 模型的 `FACIAL_*_Hair`)、眉毛、发夹等饰品不会被当成头发;
   - 每条链的第一节,以及一开始就贴在身体上的节,**不和身体碰撞**(否则会一直抖),
     所以整条压在颈背上的马尾/长发,大动作时可能穿过肩背。
5. 胸部物理新建胸骨时,可以先只点「1. 胸骨 + 权重」,确认 `左胸`/`右胸` 的骨尾落在乳尖附近,再点 2。

## 6. 导出 PMX

1. 物体模式下单击模型里任意一个对象(骨架即可),让它成为选中的活动对象。
   (导出菜单是灰的 = 当前活动对象不在模型里。)
2. (可选)改模型名:属性编辑器 → 物体属性 → **MMD Model Information** → `Name`,
   否则 MMD 里显示为 `New MMD Model`。
3. `文件 → 导出 → MikuMikuDance Model (.pmx)`,右侧选项:
   - **Scale = 12.5**(部分 mmd_tools 版本默认 1.0,不改的话模型只有十几厘米);
   - 勾 **Copy textures**(贴图会复制到 PMX 旁边的 `textures` 文件夹);
   - 其余默认。
4. 状态栏出现 `Exported MMD model ...`、文件有几 MB 即成功。

做了 Faceit(ARKit)形态键的模型,改用第三个 tab「表情」→ 工具 → **导出 PMX**(同样 ×12.5、拷贝贴图):
mmd_tools 自己的导出会把所有形态键都写成表情,这个按钮默认把 52 个 ARKit 形态键留在 Blender 里。

## 7. 在 MMD 里检查

1. 物理演算设为「**常に演算**」(默认的「再生時のみ」第一帧会跳一下,看起来像爆炸)。
2. 加载 PMX + 一段舞蹈动作,重点看:
   - 转头时头发、脸、眼睛一起动;扭腰时胯部不撕裂;脚掌跟着脚尖 IK;
   - 布、胸、头发有没有爆炸、摆动是否自然、有没有穿进身体或脸里;
   - 做了表情的:动作里的眨眼、口型、眉有没有跟着动;也可以在 MMD 的表情操作面板里逐个拖到 1 看。
3. 物理的手感以 MMD 实测为准——Blender 里的物理预览和 MMD 的物理引擎不同,只能用来查有没有炸。

## 8. 常见问题

| 现象 | 怎么办 |
|---|---|
| 导出的模型在 MMD 里极小 / 巨大 | 导出 Scale 没填 12.5;或者导入后缩放过骨架(重新导入、不要缩放,再转换一次) |
| 按钮没反应 / 行为还是旧版本 | 重启 Blender,确认面板顶部的 build 时间戳已更新;同类旧插件要禁用 |
| 手动改的槽位被还原了 | 一键转换会重新识别,手动改槽位后改走手动分步 |
| 转头时头不动、或手脚错乱 | 自动识别认错了骨:核对槽位(尤其 頭/首/上半身/腕/足),改对后走手动分步 |
| 头发物理提示「没找到发骨」 | 发骨名字里没有 hair/髪 等字样:姿态模式选中各条发链的第一根骨,点「头发物理(只用选中骨)」;模型本身没有发骨则做不了 |
| 整顶头发一起甩、或脸跟着晃 | 旧版布物理按钮把发根/脸部骨也当头发了。旧刚体没有标记,「清除头发物理」删不掉,新版头发物理也会跳过它们:重新转换后用新版「头发物理」(或在大纲视图里手动删掉这些骨上的刚体/关节) |
| MMD 里布或头发炸开 | 先确认物理演算是「常に演算」、导出前没点过 Build;仍炸就截图/录屏反馈 |
| 跳舞时某块布钉在原地拉成横板 | 那块网格权重丢了。用新版重新转换(转换时具名的布/发/胸骨会保留权重) |
| 生成表情提示「没有可用的来源」 | 模型既不是 MetaHuman / FF7 脸骨、也没有 ARKit 形态键、也没认出骨骼脸(大多数普通 MMD/XPS 模型的脸只有眼球骨),做不了;能摆脸的话可以用「姿势库」 |
| 提示「FF7 脸骨，但没找到表情数据」 | 在来源下面的「表情数据」里选这个角色的 JSON(ripper_tpose 的 `ff7rb_face_data.py` / `ff7_face_data.py` 生成) |
| 手调后生成出来没变化 | 确认「手调优先」开着、表情名选对了;手调要点「保存手调」后再点「生成表情」才会烘焙进形态键 |
| ARKit 提示「脸骨来源只做 MMD 表情」 | MetaHuman 脸没给 DNA:ARKit 要 DNA,填上 `.dna` 再生成 |
| 提示 Faceit 未安装 / 未启用 | 形态键已经生成了;装好 Faceit 并在偏好设置里启用后,点「注册到 Faceit」 |
| 分析时提示「脸部权重被截成 4 个」 | UE Viewer 导出的脸每个顶点只留 4 个权重,用 DNA 做的表情会鼓包:工具里选游戏包点「恢复完整权重」 |
| MMD 里动作的表情没反应 | 在 MMD 表情操作面板里手动拖一个(如 まばたき)看是否会动:会动说明动作用的表情名不在做出来的表情里;不动的话确认导出的是生成表情之后的模型 |

## 9. 已知限制

- **手腕小指侧拉尖**:部分模型的小指骨权重一直延伸到手腕,小指大幅弯曲时手腕外侧被拉。
- **抬臂时肩窝褶皱**:UE 骨架的肌肉修正骨在游戏里靠驱动器带动,MMD 里只能跟着上臂走。
- **没有 `両目` 骨**:动作里的双眼关键帧不起作用。
- **表情**:要有能动的脸(MetaHuman 脸骨 / DNA、ARKit 形态键、骨骼脸或自己摆的姿势);照れ(脸红)、
  星目这类要换贴图/材质的表情没有(瞳小 只有 DNA 来源能做);MetaHuman 脸骨来源做不了 ARKit(要 DNA);
  游戏模型的舌头很简陋(Fiona 只有约 40 个顶点),ぺろっ 看起来偏方;张到最大的 あ２ 从侧面看下颌角后面
  有一道褶(蒙皮权重在下颌边缘过渡很硬),常用的 あ 不明显。
- **头发**:只复用已有发骨;贴着身体的发链不撞身体(见第 5 节);UE 模型的发链常被切成很多
  1~2cm 的小节,刚体数量会很多(如 Fiona 254 个),MMD 能跑但更吃性能。
- 骨名既不是 XPS 标准名、结构又特殊的骨架,自动识别可能认错,转换前请核对槽位。
